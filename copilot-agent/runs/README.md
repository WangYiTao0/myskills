# Copilot 回答收集说明

在 Copilot 里手工提问，把回答存进这里，再用 `evaluate.py` 评测。Copilot 的操作全部由人手工完成，脚本只读存下来的文件。

## 保存位置和命名

- 一道题一个目录：`runs/<轮次>-<题号>-<短名>/`，例如 `runs/r1-q1-inbound-check/`。
- 目录里放一份 `question.md`：原样记下发给 Copilot 的提问（评测时自动跳过）。
- 每次回答存一个文件：`01.md`、`02.md` … `05.md`。不删减、不修改。
- 复制方法：Copilot 把文稿显示成一个带标题「Markdown」的卡片，默认是排好版的预览。**点卡片右上角的复制按钮**，粘贴到文件里；粘出来的内容如果没有 ```` ``` ```` 行，就在前后各补一行 ```` ```markdown ```` 和 ```` ``` ````（按钮复制出来带不带这两行还没确认，待测）。不要全选整段回答复制：那样拿到的是预览文字，`#`、`-` 前面会多出 `\`，图片写法也会丢。卡片外的说明文字（如"需要补充的数据"）可以另外复制，放在代码块后面。
- 一道题至少问 5 次。每次都开新对话，避免前一次的回答影响后一次。

## 评测

```bash
python3 copilot-agent/evaluate.py copilot-agent/runs/r1-q1-inbound-check
```

输出一份 Markdown 报告：每份回答能否生成、版式名是否合法、生成器警告数、页数和每页版式，再加一致性摘要（页数、每页版式、每页副标题是否一致，逐页列出不一致的地方）。报告可以直接贴成 issue 评论。

## 只放虚构素材

提问和回答都只用虚构项目和虚构数据。不存真实公司数据、同事姓名、租户信息或截图；回答里出现这类内容时，不提交这份回答。

## 快测步骤（只有指令、没有知识库）

不建 agent，直接在 Copilot Chat 里测：

1. 开新对话，把 `copilot-agent/instructions.md` 全文粘贴发送，并说明"以下对话按这份说明回答"。
2. 等 Copilot 确认后，把该题 `question.md` 里的提问原样发送。
3. 复制回答，存成下一个编号的文件。
4. 重复 1–3，共 5 次。
5. 跑评测，把报告贴到对应票的评论里。
