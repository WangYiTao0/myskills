\# 项目背景 / BACKGROUND

\## 纸质记录需二次录入，批次结论依赖人工查找

Layout: process

1. 纸质记录 | 检验结果填写在纸质检验单
2. 二次录入 | 每天下班前由检验员录入 Excel
3. 每周汇总 | 每周五汇总数据并提供给采购
4. 批次查询 | 收到供应商询问后翻查纸质检验单

改前检验结果经过纸质记录和 Excel 录入，批次查询需要人工翻单

\# 项目目标 / TARGET

\## 检验结果提交即入库，照片与周报同步电子化

Layout: image-text

img/项目目标示意图.png

\- 检验员在平板上填写电子检验单

\- 不良品照片随检验记录上传

\- 检验单提交后直接写入系统

\- 系统根据检验记录自动生成供应商质量周报

项目覆盖记录、照片和周报三个环节，减少重复录入与人工汇总

\# 应用场景 / USE CASES

\## 检验、拍照、入库和周报生成在同一流程内完成

Layout: process

1. 平板填单 | 检验员录入批次信息与检验结论
2. 上传照片 | 对不良品拍照并关联对应检验单
3. 提交入库 | 提交后检验记录直接进入系统
4. 自动汇总 | 系统根据记录生成供应商质量周报

电子检验单提交后直接入库，并用于自动生成供应商质量周报
