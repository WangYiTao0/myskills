# 改前改后 / BEFORE-AFTER
## 检验单改为平板填写，提交即入库
Layout: before-after
A 车间同一批检验员，改前改后的工作方式

### Before: 纸质检验单
手写纸质检验单，下班前录入 Excel，每周五手工汇总周报

### After: 电子检验单
平板填写并拍照上传，提交即入库，每周一自动生成周报
