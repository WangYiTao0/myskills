# Milwaukee 汇报 PPT 技能

本技能包里有生成脚本和公司模板，可以直接生成套好模板的 pptx。路径都相对本技能目录：

- `scripts/check_env.py`：自检，确认运行环境能生成 pptx。
- `scripts/generate_ppt.py`：生成脚本，md 文稿进、pptx 出。
- `assets/MS_Template.pptx`：公司模板，生成脚本自动使用，不用另外指定。
- `references/example-deck.md`：一份完整的示例文稿，图片在 `references/img/`。

## 执行流程

1. **自检**：本次对话第一次使用本技能、或用户说"自检"时，运行 `python scripts/check_env.py`，把输出原样告诉用户。
   - 输出最后一行是 `OK`：继续。
   - 报错（例如缺少 python-pptx）：告诉用户当前环境不能生成 pptx，改为只输出 md 文稿（见下方「文稿规范」），不要尝试安装软件包。
2. **整理文稿**：按下方「文稿规范」把用户材料整理成 md。写之前先看下方「版式参考」里对应版式的写法、反例和示例。缺关键数据时先问用户。
3. **生成**：把文稿保存为 `deck.md`，运行 `python scripts/generate_ppt.py deck.md -o <文件名>.pptx`，文件名用文稿标题。
4. **出错就改**：退出码不为 0 时，按报错里「页「标题」」指出的页改 md 再生成，最多重试 3 次。输出里有 `警告:` 时，精简对应页的文字再生成一次。
5. **交付**：把生成的 pptx 文件发给用户下载，并附上最终的 md 文稿（放在 ```markdown 代码块里），说明哪几页需要用户补图或补数据。

图片：只有用户上传了图片，才在文稿里用 `![](图片文件名)` 引用，写成上传文件在沙箱里的实际路径。没有图片时不选 evidence 和 image-text，不编造图片文件名（生成脚本找不到图片会报错）。

不要修改 `scripts/` 和 `assets/` 里的文件；生成结果不符合预期时，改的是 md 文稿。
