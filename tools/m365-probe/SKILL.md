# M365 技能沙箱探针

用来确认 M365 Copilot 技能沙箱的环境，不做别的事。

1. 运行本技能目录下的脚本：`python3 probe.py`（找不到 `python3` 就用 `python`）。
2. 把脚本的**全部输出原样**放进代码块贴给用户，不要总结、不要省略，直到 `PROBE DONE`。
3. 输出里 `write_output: OK ...` 后面是生成的文件路径；把这个文件作为可下载文件交给用户。
4. 如果脚本没跑起来，原样报告错误信息，以及你实际执行的命令和工作目录。
5. 再回答一句：你看到的本技能目录路径是什么、能不能看到同一个 agent 里其他技能（如 milwaukee-ppt）的文件。

不要改脚本、不要装包、不要联网。
