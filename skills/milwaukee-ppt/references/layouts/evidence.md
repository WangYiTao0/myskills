# evidence（默认）· 证据页

跨版式共用的文稿格式、正文区 / lead / Next 几何、共用字号与形状名、审核的几何豁免见 `references/layouts.md`；选哪个版式看那里的「选版速查」。

模板 layout 0。月报主力版式：截图或实物证据为主体 + 结论（通用 / 项目模式为标题下的 lead，月报模式为底部红条）。

```markdown
# 项目背景 / BACKGROUND
## 纸质登记让借还记录难以追溯
![](img/paper-log.png)
抽查 3 个月的登记本，约三成借出记录没有归还登记
Next: 10 月底前完成全部工具贴码
```

- 字段：0–3 张图。图在内容区（0.56 / 1.30 / 12.2 / 4.3"）里横排，各自保持比例、不裁切；多张图宽高比差别大时按比例分宽度（需要 Pillow，没有就等分）。
- 适用：一个工作项的证据——系统界面、文档、表格、现场照片。
- 反例：只有文字没有证据，改用 process / stats / image-text；4 张以上图塞一页，拆页。
- 审核：没放图时 `review_deck.py` 报「缺配图」（生成器照样能出页，只有结论）。
- 警告：图超过 3 张（只用前 3 张）；lead 超过两行（通用 / 项目模式）；红条文字顶到 5.60"（月报模式）。
