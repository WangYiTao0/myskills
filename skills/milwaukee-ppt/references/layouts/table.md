# table · 表格页

跨版式共用的文稿格式、正文区 / lead / Next 几何、共用字号与形状名、审核的几何豁免见 `references/layouts.md`；选哪个版式看那里的「选版速查」。

模板 layout 0（和 evidence、section、agenda、team 共用；inspect 靠 `Data Table` 认出 table）。md 管道表格转成原生 pptx 表格，生成后在 PowerPoint 里照常按单元格改。

```markdown
# 充电等待 / WAITING
## B 仓等待最长，排班先从 B 仓调
Layout: table
| 仓库 | 叉车数 | 平均等待 | 高峰时段 |
| --- | --- | --- | --- |
| A 仓 | 12 台 | 18 分钟 | 8:00–9:00 |
| !B 仓 | 20 台 | 35 分钟 | 13:00–14:00 |
| C 仓 | 9 台 | 12 分钟 | 8:00–9:00 |
B 仓高峰等待 35 分钟，是 A 仓的两倍
```

- 字段：一个 md 管道表格，每行以 `|` 开头；第一行是表头，表头下的分隔行（`| --- |`）可写可不写。每行列数和表头相同；表头每格必填，正文格可以空。最多一行在**第一格开头**写 `!` 标重点。其余普通文字行是一句结论（通用 / 项目模式画成 lead，月报模式进底部红条），`Next:`、`Tag:` 照常可用。
- 容量：2–6 列；表头以外 2–8 行。每格最多 2 行，列等宽，按列数算每格约多少字：2 列约 60 个汉字、3 列约 39、4 列约 29、5 列约 22、6 列约 18（英文字母约是汉字的 1.8 倍）。行高按该行最多的行数定，整张表还要放进正文区：月报模式 1.30–5.60"（写了 Tag 时从 1.50" 起），例如 6 列 × 8 行带 Tag 时，最多 3 行有两行字的格子，超出时报错，按提示拆页、删次要列或把格子写短；通用 / 项目模式按本页正文区（随 lead / Next 变）判断，最小一档字号也放不下时只警告。每格字数按 14pt 算（上面的字数）。
- 主标题、副标题照常填 idx 0 / 10；副标题写表格要说明的结论（哪一行最突出），不要写成「数据汇总」。
- 结论：保留（通用 / 项目模式画成 lead，月报模式进底部红条）。表格页通常有一句读表结论，写在表格后面；没写时审核照常报「缺结论行」。
- 画法（月报模式）：表格占正文区全宽（左边留 0.12" 给红竖条），从正文区上沿排起，写了 Tag 时下移到月份标识下面；列等宽。全表 14pt #1A1A1A：表头加粗、#E5E5E5 底、下边 1.5pt #1A1A1A；正文无底色，每行下边 0.75pt #BFBFBF 细线，没有竖线；单元格内边距左右 0.1"、上下 0.06"，文字垂直居中。表格不引用主题表格样式（主题样式会带出 accent 色），底色、边框都显式写。
- 画法（通用 / 项目模式，方向 C）：样式同上，字号随行数放大——按 18pt（上下内边距 0.09"）→ 16pt（0.08"）→ 14pt（0.06"）从大到小试，取第一档「每格不超过 2 行、整表放得进正文区」的，行高按字号 × 1.25 加内边距跟着变；整张表在正文区里垂直居中（写了 Tag 时不高于月份标识下沿），行少时下方不再留大片空白。`Table Key Bar` 跟着 `!` 行的位置和行高走。
- `!` 强调（SKILL.md §6.3 红色纪律）：标了 `!` 的那一行文字加粗，左侧一条 0.06" 宽的品牌红竖条（和这一行同高）；表格本身只用黑白灰，不把整行染红、不加红底。成果页标最该被记住的一行，问题页标风险最高的一行。
- 适用：同一组对象在几个维度上的对比（各仓库 / 车间 / 供应商的数量、耗时、状态）、试点范围清单、问题清单的现状和负责人。
- 反例：只有 2–4 个数字要讲（用 stats，数字更醒目）；有先后顺序的步骤（用 process）；时间节点（用 timeline）；表格超过 8 行 6 列（拆页，或只留关键行列，完整明细放附件）；单元格里写成一段话（表格只放短词和数字，解释写进结论）。
- 报错：没有表格；列数不在 2–6、表头以外行数不在 2–8；某行列数和表头不同；表头有空格；某格超过 2 行；表格总高放不进正文区（月报模式；通用 / 项目模式只警告）；`!` 多于一行、写在表头或非第一格、写成 `!!`；表格行漏写开头 `|`（免得悄悄变成结论）；写了列表行。报错信息带页标题。
- 审核：`review_deck.py` 对 table 和其他有结论的版式一样检查「缺结论行」「目录式副标题」；几何检查不需要另加豁免（表格是一个形状 `Data Table`，红竖条在表格左边、不和它重叠）。文字溢出另按单元格估算：某行文字估计高过行高时报「文字溢出」（PowerPoint 会把行撑高，表格往下压到页底 Next 行 / 红条）。

## 字号

本版式专属的字号行（共用行见 `references/layouts.md`「共用排版」的字号表）。

| 用途 | 字号与样式（Arial；中文 PingFang SC） |
| --- | --- |
| 表格（通用 / 项目模式） | 18pt #1A1A1A，表头加粗（放不下时整表降到 16 / 14pt） |

## 形状名

生成器给本版式画的形状名（编号规则、各版式共用的形状见 `references/layouts.md`「形状命名约定」）。

| 范围 | 形状名 |
| --- | --- |
| table | `Data Table`（原生表格，graphicFrame；第一行是表头，单元格按 `shape.table.cell(行, 列)` 取，行列从 0 起；`Data Table` 也是 inspect 区分 table / team / agenda / section / evidence 的标记形状）、`Table Key Bar`（`!` 行左侧的红竖条，只在标了 `!` 时有） |
