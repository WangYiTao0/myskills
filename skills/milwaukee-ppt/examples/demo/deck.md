# 新流程 / PROCESS
## 借还改为扫码登记，四步完成
Layout: process
1. 贴码 | 每件工具贴唯一二维码
2. 扫码借出 | 扫码自动带出工具信息
3. 到期提醒 | 到期前一天推送提醒
4. 扫码归还 | 归还时扫码，自动入库
新流程已在试点车间运行 4 周
