# 项目背景 / BACKGROUND
## 纸质登记让借还记录难以追溯
Tag: Oct
![](img/paper-log.png)
抽查 3 个月的登记本，约三成借出记录没有归还登记
Next: 10 月底前完成全部工具贴码

# 新流程 / PROCESS
## 借还改为扫码登记，四步完成
Layout: process
1. 贴码 | 每件工具贴唯一二维码
2. 扫码借出 | 扫码自动带出工具信息
3. 到期提醒 | 到期前一天推送提醒
4. 扫码归还 | 归还时扫码，记录自动闭环
新流程已在试点车间运行 4 周
